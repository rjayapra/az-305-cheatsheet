# AZ-104: Microsoft Azure Administrator - Complete Study Guide

## 📋 Exam Overview

| Detail | Info |
|--------|------|
| **Exam** | AZ-104 |
| **Title** | Microsoft Azure Administrator |
| **Certification** | Microsoft Certified: Azure Administrator Associate |
| **Prerequisite** | None (AZ-900 recommended but not required) |
| **Questions** | 40-60 (multi-choice, drag-and-drop, hot area, case studies) |

| **Passing Score** | 700/1000 |
| **Focus** | Implementation & management (hands-on, not design) |

---

## 🎯 Skills Measured (5 Domains)

### Domain 1: Manage Azure Identities and Governance (20-25%)
- Microsoft Entra ID users, groups, and devices
- Role-Based Access Control (RBAC) and custom roles
- Azure subscriptions and management groups
- Azure Policy and resource locks
- Resource tagging and cost management

### Domain 2: Implement and Manage Storage (15-20%)
- Storage accounts (types, redundancy, access tiers)
- Blob storage and lifecycle management
- Azure Files and Azure File Sync
- Storage security (SAS tokens, access keys, stored access policies)
- Import/Export and AzCopy

### Domain 3: Deploy and Manage Azure Compute Resources (20-25%)
- Virtual machines (create, configure, manage)
- VM availability (Availability Sets, Zones, VMSS)
- Azure App Service and deployment slots
- Azure Container Instances and Azure Kubernetes Service
- ARM templates, Bicep, and automation

### Domain 4: Implement and Manage Virtual Networking (15-20%)
- Virtual networks, subnets, and IP addressing
- Network Security Groups (NSGs) and Application Security Groups (ASGs)
- Azure DNS (public and private zones)
- VNet peering, VPN Gateway, and ExpressRoute
- Azure Load Balancer and Application Gateway

### Domain 5: Monitor and Maintain Azure Resources (10-15%)
- Azure Monitor and Log Analytics
- Azure alerts and action groups
- Azure Backup and Recovery Services Vault
- Azure Network Watcher
- Resource health and service health

## 🧠 Key Concepts to Master

### Azure CLI vs PowerShell - Know Both
```bash
# Azure CLI (Bash-style, cross-platform)
az group create --name MyRG --location eastus
az vm create --resource-group MyRG --name MyVM --image Ubuntu2204 --size Standard_B2s

# Azure PowerShell
New-AzResourceGroup -Name MyRG -Location eastus
New-AzVM -ResourceGroupName MyRG -Name MyVM -Image Ubuntu2204 -Size Standard_B2s
```

### ARM Template Structure
```json
{
  "$schema": "...",
  "contentVersion": "1.0.0.0",
  "parameters": {},
  "variables": {},
  "resources": [],
  "outputs": {}
}
```

### Key Azure CLI Commands to Know
```bash
# Identity
az ad user create / list / delete
az role assignment create --assignee <id> --role "Contributor" --scope <scope>

# Storage
az storage account create / show / list
az storage blob upload / download / copy

# Compute
az vm create / start / stop / deallocate / resize
az vmss create / scale

# Networking
az network vnet create / show
az network nsg rule create
az network lb create

# Monitoring
az monitor metrics list
az backup protection enable-for-vm
```

## 💡 Exam Tips

1. **Implementation, not design** - AZ-104 asks HOW to do things, not WHICH service to pick
2. **Know the Portal, CLI, and PowerShell** - Questions test all three
3. **Read requirements carefully** - "minimum cost" vs "minimum effort" changes the answer
4. **NSG rules** - Lower priority number = higher priority; default rules can't be deleted
5. **Storage account names** - Globally unique, 3-24 chars, lowercase + numbers only
6. **VNet peering is non-transitive** - A↔B + B↔C ≠ A↔C
7. **Deallocate vs Stop** - Deallocate releases compute resources (stops billing); Stop keeps them reserved
8. **Manage time** - Don't spend >2 min per question; flag and return
