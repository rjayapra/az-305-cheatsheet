## 🎯 Skills Measured (4 Domains)

### Domain 1: Design Identity, Governance & Monitoring Solutions (25-30%)
- Microsoft Entra ID (Azure AD) architecture
- Hybrid identity solutions (Azure AD Connect, Cloud Sync)
- Privileged Identity Management (PIM)
- RBAC and Conditional Access policies
- Management groups, subscriptions, resource groups hierarchy
- Azure Policy, Blueprints, Landing Zones
- Cost management and governance at scale
- Azure Monitor, Log Analytics, Application Insights
- Security monitoring and alerting strategies

### Domain 2: Design Data Storage Solutions (20-25%)
- Azure SQL (Database, Managed Instance, SQL on VMs) selection
- Cosmos DB (consistency models, partitioning, global distribution)
- Azure Storage Accounts (Blob, Table, Queue, Files)
- Azure Data Lake, Synapse Analytics
- Redis Cache, Azure Search
- Data redundancy and replication strategies
- Backup/restore architecture
- Hybrid storage solutions (StorSimple, Azure File Sync)

### Domain 3: Design Business Continuity Solutions (15-20%)
- High Availability (HA) architecture patterns
- Disaster Recovery (DR) design
- RTO/RPO requirements and SLA calculations
- Azure Backup strategies
- Azure Site Recovery (ASR)
- Geo-redundancy and multi-region deployments
- Failover and failback procedures
- Application resilience patterns

### Domain 4: Design Infrastructure Solutions (30-35%)
- Compute: VMs, VMSS, AKS, Container Apps, Azure Functions, App Service
- Networking: VNets, Peering, ExpressRoute, VPN Gateway, Virtual WAN
- Hub-and-spoke topology, Network Virtual Appliances
- Load balancing (Application Gateway, Front Door, Traffic Manager, Load Balancer)
- Application architecture (microservices, event-driven, serverless)
- Migration strategies (Azure Migrate, Database Migration Service)
- Cost optimization and FinOps
- Hybrid connectivity patterns

## 🧠 Key Decision Frameworks to Memorize

### Compute Selection
```
Web App (simple) → App Service
Containers (orchestration needed) → AKS
Containers (simple/serverless) → Container Apps
Event-driven/short tasks → Azure Functions
Full OS control needed → Virtual Machines
Batch processing → Azure Batch
```

### Storage Selection
```
Relational + high compatibility → Azure SQL Database
Relational + full SQL Server features → SQL Managed Instance
NoSQL + global distribution → Cosmos DB
Unstructured blobs → Azure Blob Storage
File shares (SMB/NFS) → Azure Files
Analytics → Azure Synapse / Data Lake
Caching → Azure Cache for Redis
```

### Load Balancing Selection
```
Global HTTP/HTTPS → Azure Front Door
Global non-HTTP → Traffic Manager
Regional HTTP/HTTPS (with WAF) → Application Gateway
Regional non-HTTP → Azure Load Balancer
```

### Redundancy Selection
```
Single region, single datacenter → LRS
Single region, zone protection → ZRS
Multi-region, async → GRS
Multi-region, read access → RA-GRS
Multi-region, zone + geo → GZRS
```

## 💡 Exam Tips

1. **Focus on DESIGN, not implementation** - The exam asks WHY, not HOW
2. **Eliminate wrong answers** - Usually 2 options are clearly wrong
3. **Cost matters** - If two solutions work, pick the cheaper one
4. **Least privilege** - Always choose minimum required permissions
5. **Managed services preferred** - PaaS over IaaS when possible
6. **Read case studies carefully** - Requirements often have subtle constraints
7. **Time management** - Don't spend >3 min per question; flag and return
8. **SLA multiplication** - Combined SLA = SLA₁ × SLA₂ × SLA₃...

## 🔄 Reusable Certification Prep Framework

This framework can be applied to ANY certification:

### Phase 1: Discovery (Day 1-2)
1. Download official exam skills measured document
2. Self-assess current knowledge per domain (1-5 scale)
3. Identify primary study resources (video, reading, labs)
4. Create study schedule based on days available

### Phase 2: Foundation (30% of time)
1. Watch overview/introductory content for each domain
2. Read official documentation for weak areas
3. Take initial practice test to establish baseline

### Phase 3: Deep Dive (40% of time)
1. Focus on weakest domains first (highest ROI)
2. Hands-on labs for every major concept
3. Take notes on key decision points and trade-offs
4. Work through case studies/scenarios

### Phase 4: Validation (20% of time)
1. Take full-length practice exams
2. Review incorrect answers thoroughly
3. Re-study weak areas identified

### Phase 5: Final Prep (10% of time)
1. Watch exam cram/review videos
2. Review cheat sheets and decision trees
3. Light review on exam day - don't cram new material
4. Rest well the night before

### Required Skills for Any Cert Prep
- **Time management** - Stick to your schedule
- **Active recall** - Test yourself, don't just re-read
- **Spaced repetition** - Review topics at increasing intervals
- **Hands-on practice** - Build, break, rebuild
- **Community engagement** - Forums, study groups, Discord
- **Exam strategy** - Know question types and time allocation
