## 📐 Step 4: Study Schedule Template

### Time Allocation Formula
```
Total Days Available = X

Foundation Phase:  30% of X = __ days
Deep Dive Phase:   40% of X = __ days  
Validation Phase:  20% of X = __ days
Final Prep Phase:  10% of X = __ days (min 1 day)
```

### Daily Study Template
```
[ ] 30 min - Review previous day's notes (spaced repetition)
[ ] 60 min - Video/Reading for current topic
[ ] 45 min - Hands-on lab or exercise
[ ] 30 min - Practice questions (10-15 questions)
[ ] 15 min - Note key takeaways and weak areas
```

### Weekly Milestones
- **End of Week 1:** All domains covered at surface level. Baseline practice test taken.
- **End of Week 2:** Deep dive on priority domains complete. 2nd practice test 75%+.
- **End of Week 3:** All practice tests 80%+. Case studies comfortable. Exam ready.

## 📐 Step 5: Study Techniques

### Active Recall Methods
1. **Flashcards** - Use Anki or physical cards for key facts
2. **Teach-back** - Explain concepts aloud as if teaching someone
3. **Practice tests** - Test before you feel ready
4. **Whiteboarding** - Draw architectures/flows from memory

### Spaced Repetition Schedule
```
Day 1: Learn new topic
Day 2: Quick review (5 min)
Day 4: Review again
Day 7: Final review
```

### Note-Taking Framework
For each topic, capture:
- **What** - Core concept in 1-2 sentences
- **When** - Use cases / scenarios where this applies
- **Why not** - When to choose alternatives
- **Gotchas** - Common mistakes or edge cases

## 📐 Step 6: Practice Test Strategy

### When to Take Practice Tests
| Test # | When | Purpose | Target Score |
|--------|------|---------|--------------|
| 1 | After foundation phase | Baseline & gap analysis | No target |
| 2 | Mid deep-dive | Progress check | 70% |
| 3 | End of deep-dive | Readiness check | 80% |
| 4 | Day before exam | Confidence builder | 85%+ |

### After Each Practice Test
1. Review ALL incorrect answers (understand WHY)
2. Review correct answers you were unsure about
3. Update priority list based on weak domains
4. Add new flashcards for missed concepts

## 📐 Step 7: Exam Day Strategy

### Before the Exam
- [ ] Light review only (cheat sheets, decision trees)
- [ ] No new material on exam day
- [ ] Arrive early / set up workspace early
- [ ] Have ID ready (for test center) or system checked (online)

### During the Exam
- [ ] Read each question FULLY before looking at answers
- [ ] Eliminate obviously wrong answers first
- [ ] Flag uncertain questions - don't waste time
- [ ] Watch for keywords: "MOST cost-effective", "LEAST administrative effort"
- [ ] Time check: questions_remaining × 2 min < time_remaining
- [ ] Case studies: Read requirements BEFORE the questions

### Key Decision Principles (most certs)
- **Least privilege** - Minimum permissions needed
- **Cost optimization** - Cheapest working solution
- **Managed services** - PaaS over IaaS when possible
- **Simplicity** - Fewer moving parts = better
- **Scalability** - Solutions that handle growth

---

## 📐 Step 8: Post-Exam

### If You Pass ✅
- Update LinkedIn/resume
- Claim digital badge
- Note renewal requirements
- Plan next certification

### If You Don't Pass ❌
- Review score report per domain
- Identify weakest domains
- Wait required period (usually 24 hours for retake)
- Focus study on lowest-scoring domains
- More practice tests before retaking
- Don't be discouraged - many pass on 2nd attempt
